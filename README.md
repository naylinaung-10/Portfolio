# 制作プロセス

a.要件確認
ご依頼内容や仕様、使用条件、必要な精度・寸法などを確認します。

b.設計・モデリング
仕様に基づいて構想を検討し、2D図面や3D CADモデルを作成します。

c.設計検討・解析
形状、強度、干渉、製作性などを確認し、必要に応じてCAE・FEA解析やCFD解析を行います。

d.修正・最適化
検討結果やフィードバックをもとに、形状・寸法・仕様を修正し、設計を最適化します。

e.最終確認・納品
図面・3Dモデルの整合性や仕様を確認し、必要なデータ形式にまとめて納品します。
